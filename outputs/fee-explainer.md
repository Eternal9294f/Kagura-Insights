# Fee explainer: Exit load (mutual funds)

Last checked: 14 Oct 2026

- Exit load is a fee charged by the mutual fund scheme (the fund house), not by Groww or any broker, when units are redeemed before a period specified for that scheme.
- The rate and qualifying period are scheme-specific and defined in each scheme's offer document/SID — for example some equity schemes charge about 1% if redeemed within a year, while many funds charge nothing after 7–30 days.
- It is deducted automatically from redemption proceeds; Groww shows the approximate exit load on the redeem order screen before you confirm.
- It is separate from brokerage, GST, STT, stamp duty and capital-gains tax — none of these are exit load.
- Redeeming before the scheme's exit load period ends reduces the amount credited; redeeming after it typically results in no deduction.
- Official sources: Groww help — What is exit load? (https://groww.in/help/mutual-funds/order/what-is-exit-load--71) · SEBI investor education — Exit Load (https://investor.sebi.gov.in/exit_load.html)
